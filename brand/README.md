# Hoiva brand

Hoiva is Finnish for "care". The mark spells HOIVA in rounded strokes arranged as a heart, with a small heart dotting the i.

| File | Use |
|---|---|
| `hoiva-logo.svg` | Primary: white letters in a teal heart |
| `hoiva-logo-mono.svg` | Letters only, teal, for light backgrounds |
| `hoiva-logo-reverse.svg` | Teal letters in a white heart, for teal or dark backgrounds |
| `hoiva-icon.svg` | App icon (square, sand background) |

## Colours

| Name | Hex | Use |
|---|---|---|
| Hoiva Teal | `#11606B` | Primary: buttons, headings, the heart. White text on it passes AAA (7.2:1) |
| Deep Teal | `#0B4048` | Hover/pressed states, dark sections |
| Heart Coral | `#FF8A78` | Accent: the heart dot, highlights. Use dark text on it, never white |
| Sage | `#8FC1B5` | Secondary: success states, illustrations, soft fills |
| Sand | `#FAF5EE` | Page and app-icon background |
| Ink | `#1C2B33` | Body text (13.4:1 on Sand) |
